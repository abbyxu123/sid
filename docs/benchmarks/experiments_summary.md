## ✅ E5. 单 Agent 一次生成 vs 完整链路（20 条用例，`e5_single_vs_multi.json`）

单侧 = 原话+30 候选一次丢给 Step 直接选（模拟"角色 Prompt 包装"做法，公平给足 3600 token）；
多侧 = 完整主链路（kitten 抽取 → 硬规则 → 议事会/规则 → 审核）。

| 方案 | 硬约束违规 | 调用失败 | 可用率 | 平均耗时 |
|---|---|---|---|---|
| 单 Agent 一次生成 | 2/20（渠道约束被无视） | 3/20（长上下文思考链耗尽） | 75% | 70.0s |
| **完整链路** | **0/20** | **0/20** | **100%** | **2.1s** |

结论：模型本身不差（15/20 单打成功），但**把保证性从 75% 提到 100%、延迟降 33 倍**的是
架构——确定性规则、职责拆分与审核，这正是"不是角色 Prompt 包装"的实证。
